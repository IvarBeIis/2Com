# Projekt: SecureWhisper – P2P šifrovaná komunikační aplikace pro Android

## Přehled dokumentace

Tato sada dokumentů specifikuje vývoj Android aplikace pro plně šifrovanou peer-to-peer komunikaci (chat, audio, video) bez centrální infrastruktury. Spojení se navazuje na základě hexadecimálního identifikátoru odvozeného z veřejného klíče uživatele.

### Pracovní kódový název: SecureWhisper
